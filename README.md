# Plateforme de gestion des épargnes et crédits

## Description

Application web permettant de gérer les clients, les comptes d’épargne, les crédits et les remboursements.

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Fonctionnalités

- Gestion des clients
- Gestion des comptes d’épargne
- Gestion des crédits
- Gestion des remboursements
